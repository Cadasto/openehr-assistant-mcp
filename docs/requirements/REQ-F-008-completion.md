# REQ-F-008 — Argument auto-completion

## Capability

Offer argument auto-completion for guide names, example names, and specification components, so a user picks
a valid value instead of typing one from memory.

## Acceptance criteria

- [x] A client receives completion suggestions for guide names, example names, and specification components.

## Out of scope

- Completion for free-text arguments such as search keywords.
