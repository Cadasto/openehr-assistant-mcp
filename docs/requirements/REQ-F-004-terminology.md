# REQ-F-004 — Terminology resolution

## Capability

Resolve openEHR terminology identifiers, codes, and rubrics, so an agent uses the right code without guessing
it.

## Acceptance criteria

- [x] An agent resolves a terminology identifier, a code, or a rubric, optionally within one group.
- [x] Resolution works offline, from the terminology bundled with the server.

## Out of scope

- External terminologies such as SNOMED CT or LOINC.
